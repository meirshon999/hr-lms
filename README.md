# PEG HR LMS v1 — документация

Логика системы онбординга новых сотрудников Pingwin Premium: описание того,
**как система должна работать**, плюс **рабочий прототип**, который это
поведение реализует.

## Быстрый старт

1. **Посмотреть, что это** — открой `PEG-HR-LMS.pdf` (вся логика + схемы, 10 минут).
2. **Потрогать** — `cd prototype && npm install && npm run dev` → http://localhost:5173
   (демо-аккаунты и сценарий показа — на экране входа). Swagger API — http://localhost:3001/docs
3. **Интегрировать** — `prototype/README.md`, раздел «Интеграция в платформу коллеги»:
   что переносится как есть, что заменить платформенным.

Прототип реализует спецификацию целиком и служит эталоном поведения.
Запуск — `cd prototype && npm install && npm run dev`, детали в `prototype/README.md`.

Порядок чтения: `LOGIC.md` → `SPEC.md` → `DESIGN.md` (в PDF именно так).

## Как отправить коллеге

**Для ознакомления и правок** — пошли `PEG-HR-LMS.pdf`. Один файл, открывается
везде, схемы внутри.

**Чтобы он запустил прототип и продолжил** — пошли папку `prototype/` (без
`node_modules/` — он поставит сам). Плюс `SPEC.md` рядом как референс.

**Чтобы скармливать Claude** — `SPEC.md` + `openapi.yaml` + `LOGIC.md` +
`DESIGN.md` + `prototype/`. `SPEC.md` даёт правила и сущности, `openapi.yaml` —
точный контракт API, прототип — эталонное поведение.

**Если коллега на GitHub** — залей корень проекта (без `node_modules/`, `.build/`,
`*.db`) в приватный репозиторий. GitHub рендерит и Markdown, и mermaid-схемы
прямо в `LOGIC.md`.

## Область v1

Только онбординг новичков: `стажёр → онбординг → завершил → архив`. Один backend-
сервис. Вход логин+пароль. Онбординг открывает кнопка HR «Стажировка пройдена».
Тесты — авто-проверка, без лимита попыток. Контент собирается в конструкторе;
при открытии онбординга траектория **замораживается снимком**, поэтому правки
каталога не ломают тех, кто уже учится. Часовой пояс — `Asia/Almaty`.

**Вне v1** (см. `SPEC.md` §10): переаттестация, курсы действующим, филиалы,
переводы, уведомления, геймификация, биометрия, импорт списком, экраны
руководителя.
