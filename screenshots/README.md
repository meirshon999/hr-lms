# Скриншоты для слайдов

Сняты с работающего стенда автоматически, в реальных размерах экранов:
телефон — 390×844, компьютер — 1440×900, retina (×2).

Пересобрать после правок интерфейса: `node prototype/audit-ui.mjs`
(нужен запущенный стенд и Chrome).
